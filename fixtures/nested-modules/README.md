# Fixture: nested-modules

A minimal two-level module tree, generated by real Terraform, that exercises the two
things the flat fixture cannot:

1. **Addresses join across two shapes.** `planned_values` uses absolute addresses
   (`module.agent.aws_iam_role.exec`); `configuration` uses addresses relative to their
   module (`aws_iam_role.exec`). Joining them naively finds nothing, and every resource
   inside a module looks like it references no role.
2. **Cross-module wiring goes through input variables.** The Lambda in `module.tools`
   says `role = var.role_arn`. Only the parent's
   `module_calls.tools.expressions.role_arn` knows that this is `aws_iam_role.exec`, so
   resolving it means walking one module outward.

Real Terraform is mostly modules, so both paths are load-bearing for anyone pointing this
at their own infrastructure. `plan.json` is checked in; regenerate with `make fixture-plan`.
